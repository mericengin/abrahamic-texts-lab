# Contributing

Thanks for your interest. This is a small, non-profit research project, and careful corrections matter more than volume. Scholars of religious studies and ancient languages are especially welcome.

## Good contributions

- **Source and license corrections.** If a license, URL or attribution in [SOURCES.md](SOURCES.md) is wrong, please say so and link the primary page.
- **Missing open sources.** Suggest a text with its license and the page that states it.
- **Text and alignment fixes.** Versification mismatches, encoding problems, wrong references.
- **Gold-set and annotation review** from domain experts.
- **Code and tests** for parsers, alignment and analysis.
- **Accessibility and design feedback** for the web app.

## Ground rules

1. **Never commit third-party texts or datasets.** Add or update a manifest entry and a parser instead.
2. **Check the primary license page** and quote the key wording. Search snippets and aggregators are not enough.
3. **No fabricated results or citations.** Say what was not run. Report negative results.
4. **Descriptive, never evaluative.** Do not rank or judge traditions.
5. **Show uncertainty.** Dates are ranges; automated output carries a confidence.
6. **Free resources only.** Do not add paid services or API keys.

## Workflow

1. Open an issue describing the change, or start from an item in [ROADMAP.md](ROADMAP.md).
2. Keep changes small. Add tests (`python3 -m unittest discover -s tests`).
3. Update [CHANGELOG.md](CHANGELOG.md) for user-visible changes, and the docs if behavior or scope changes.
4. Tick a roadmap box only when the work exists and has been checked.

## Reporting a problem

Please include the text or source concerned, what is wrong, and a reference. If you believe a text is being used against its license, open an issue and it will be looked at promptly.

## Conduct

Be respectful. Discussion of the texts is about evidence and method, not about whose tradition is right.
